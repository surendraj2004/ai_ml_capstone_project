# Capstone Project

This repository contains my capstone project developed as part of my learning journey in artificial intelligence(AI) and machine learning(ML).

As a fresher, this project helps me apply the concepts and tools I have learned through practical implementation.

## Project Modules

### 1. Data Pipeline
This module focuses on:
- Data collection through scraping
- Data cleaning
- Data transformation
- SQLite database operations
- SQL analysis

### 2. Analytics
This module focuses on:
- Exploratory Data Analysis (EDA)
- Data visualization
- Understanding datasets
- Machine Learning basics
- Model evaluation

### 3. Support Assistant
This module focuses on building an AI-powered support assistant for zepto company.
